# 🤖 AI Probe Book

AI Probe Book is a management platform for creating, monitoring, and controlling AI-driven survey conversations for product market research. It lets you switch between different AI models (like ChatGPT or Gemini), set up dynamic prompts, and customize chat interfaces.

## 🚀 Key Features

* Multi-AI Provider: Easily switch between OpenAI, Gemini, or custom AI models.
* Smart Prompt Engine (AutoGen): Automatically creates structured prompts using product categories, topics, and positive/negative attributes.
* Custom Chat Branding: Change colors, titles, logos (VKS, AI, Respondent), and background images.
* Survey Rules: Set minimum/maximum question limits, language rules, and block specific topics.
* Link Generation: Easily generate and export unique respondent chat links to Excel.
